ROBOTICS AND MACHINE SYSTEMS

Robots that talk to each other and decide their next step.

I built key parts of the software that turned a manual drilling operation into an automated one. About five years on drilling robotics and one on drones, mostly integration, architecture and performance tuning in C++ and Python.

01 Layers · 02 Coordination · 03 Sequences · 04 Tuning · Services

Where the software sits

Most machine systems already have robots, PLCs and services that work on their own. My work sits above them: first an integration layer that makes their state readable and writable in one way, then operational software that uses that state.

Robots that coordinate

Each robot publishes its state and reads the state of the others. Instead of one central script telling every machine what to do, each one decides its next step from what it sees: is the shared zone free, is the part in place, is the step before done.

Generic sequences with live values

A sequence is written once and reused. The values it needs are filled in while it runs, such as which item, where it is and its size. The same sequence handles a different item without being rewritten.

Performance tuning

Much of my work is making an existing system run better. I measure loop time, CPU and network load, then remove what the system does not need. The result of this work was more reliability and less downtime.
