# Yantrakar

Official website for Yantrakar AS.

## Pages

- `index.html` — single-page site (problems, work, about, contact)
- `assets/` — styles

## Run locally

Serve the repository with any static HTTP server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

GitHub Actions deploys the `main` branch to GitHub Pages using `.github/workflows/pages.yml`.

## Products section

The Products tiles in `index.html` (between `<!-- products:start -->`
and `<!-- products:end -->`) are generated by `tools/build_products.py`:

- Public repos in the Yantrakar GitHub org with the topic `yantrakar-product`
  appear automatically, with their description, homepage and latest release.
- `products.json` sets the order, overrides text and links, and lists products
  that are not public repos yet (for example Verako).
- An entry with `tagline_from` (Verako uses `https://verako.no/`) takes its
  text from that live site: meta description, then og:description, then the
  page's lead paragraph. Its `text` is only the fallback if the site is down.
- The Pages workflow runs the script on every push to `main` and daily at
  04:23 UTC. Run `python3 tools/build_products.py` locally to preview.
